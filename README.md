# EveryNode

Учебный проект по C# и бэкенд-разработке: общее поле, на котором участники размещают ограниченное число вершин графа и соединяют их рёбрами. Изменения со временем должны становиться видны всем посетителям.

## Как мы учимся

Код приложения пишет автор проекта. ИИ используется только для поиска информации в источниках и помощи в выборе начального пути. Подробное правило для следующих сессий записано в [AGENTS.md](AGENTS.md).

## Первый маршрут

1. Освоить C# и запуск простого ASP.NET Core приложения.
2. Сделать HTTP API для чтения графа и добавления вершины.
3. Добавить ограничения и операции с рёбрами.
4. Сохранить граф в базе данных.
5. Передавать обновления открытым клиентам в реальном времени.
6. Сделать простой интерфейс поля и подготовить публичный запуск.

Выбор технологий и границы первой версии описаны в [docs/PROJECT.md](docs/PROJECT.md). Первый самостоятельный шаг — в [docs/START.md](docs/START.md).
